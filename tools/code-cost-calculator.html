≡Scoring Rules

  
Lower is better.

  

  
Cost rules
Encapsulation: +2/public mutable field, +1/package-private mutable field, +2/returned internal array
Inheritance reuse: +2/redeclared parent field + duplicated parent-method cost, +2/field repeated in sibling classes
Field hiding: +2/hidden parent field
Override: +1/missing @Override
Polymorphism: +2/instanceof or getClass() outside equals, +1/cast to own class, +2/overload that repeats the work
